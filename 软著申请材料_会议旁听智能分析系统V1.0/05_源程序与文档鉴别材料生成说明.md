# 源程序与文档鉴别材料生成说明

## 一、说明

本目录已提供脚本：

- `scripts\生成软著鉴别材料.ps1`

脚本用于从当前项目目录中自动抽取源程序，并生成适合软著整理的分页文本样本。

## 二、脚本输出内容

脚本默认输出到本目录下的 `generated` 子目录：

- `源程序鉴别材料_会议旁听智能分析系统V1.0.txt`
- `文档鉴别材料_会议旁听智能分析系统V1.0.txt`

## 三、脚本规则

### 程序鉴别材料

- 自动读取 `server\src`、`web-static`、`screen-catch` 下的主要源码文件。
- 自动跳过：
  - `node_modules`
  - `.git`
  - `data`
  - 本软著材料目录
- 自动去除空行。
- 每页固定 50 行。
- 若总页数超过 60 页，则输出前 30 页和后 30 页。

### 文档鉴别材料

- 以 `02_软件说明书.md` 为主要输入。
- 自动分页为每页 30 行。
- 若总页数不足 60 页，则输出全部。

## 四、运行方式

在项目根目录 PowerShell 中执行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\软著申请材料_会议旁听智能分析系统V1.0\scripts\生成软著鉴别材料.ps1"
```

## 五、生成后建议

1. 打开生成结果，快速检查首页和末页是否完整。
2. 确认程序材料最后一页不是半截代码块。
3. 将文本导入 Word，统一设置：
   - A4
   - 单面打印
   - 页眉：会议旁听智能分析系统 V1.0
   - 合理等宽字体
4. 导出 PDF 后再提交。
