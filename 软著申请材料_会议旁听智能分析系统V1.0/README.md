# 会议旁听智能分析系统 V1.0 软著申请材料

本目录用于整理 `meet-helper` 项目的中国计算机软件著作权申请材料草稿。

## 目录说明

- `01_软著申请信息表草稿.md`
  - 对应软著申请表的可填写草稿，已按本项目实际功能预填核心内容。
- `02_软件说明书.md`
  - 作为文档鉴别材料的主体说明书，建议后续转为 `docx/pdf`。
- `03_软件功能简述.md`
  - 用于项目申报、内部审批或补充说明的简版功能简介。
- `04_材料清单与提交要求.md`
  - 按中国版权保护中心口径整理的提交清单与格式要求。
- `05_源程序与文档鉴别材料生成说明.md`
  - 说明如何导出软著所需的程序和文档鉴别材料。
- `scripts\生成软著鉴别材料.ps1`
  - 用于从当前项目生成程序鉴别材料和文档分页样本的 PowerShell 脚本。

## 建议的软件名称

- 软件全称：会议旁听智能分析系统
- 软件简称：会议旁听 Agent
- 版本号：V1.0

说明：

1. 软件全称、简称、版本号必须在申请表、源程序页眉、文档页眉中保持一致。
2. 若你准备以公司名义申请，后续只需要把申请表草稿里的著作权人、统一社会信用代码、完成日期等字段替换为实际信息。

## 本项目建议的软著定位

本系统适合作为一套“会议音视频内容采集、增量分析、同事画像构建、模拟对话与后台管理”的综合应用软件进行登记，避免把单一功能拆得过碎，导致说明书和代码对应关系变弱。

建议定位如下：

- 软件名称：会议旁听智能分析系统
- 版本：V1.0
- 开发方式：独立开发
- 权利取得方式：原始取得
- 发表状态：未发表或按你的实际首次上线日期填写

## 使用建议

1. 先通读 `01_软著申请信息表草稿.md`，把主体信息补齐。
2. 再把 `02_软件说明书.md` 转成 `docx/pdf`，并在其中补充 6-10 张关键页面截图。
3. 运行 `scripts\生成软著鉴别材料.ps1`，生成程序鉴别材料与文档分页样本。
4. 将营业执照或身份证扫描件、如有则补充委托/合作开发协议，一并提交。

## 当前项目对应的核心模块

- 会议录屏与音频采集
- 实时转写与离线回填
- 会议增量分析
- 同事画像构建与增量更新
- 同事画像模拟对话
- Spectator 主动建议与自动讨论
- 编号用户独立会话管理
- 用户画像分析
- 后台会话查询与管理

## 注意

本目录内容已经尽量按软著登记习惯整理，但最终提交前仍建议你核对：

- 著作权人名称
- 开发完成日期
- 首次发表日期
- 软件版本号
- 文档页眉和程序页眉
- 截图中显示的软件名称
