# 提交与盖章注意事项

## 一、申请表处理

1. 在中国版权保护中心系统中在线填写申请表。
2. 申请表中的软件名称、简称、版本号必须与本材料保持一致。
3. 打印系统生成的确认签章页，不要手改版式。
4. 企业申请时加盖公章；个人申请时签字。

## 二、程序和文档处理

1. 程序与文档建议统一转换为 PDF。
2. 程序页眉、文档页眉统一使用：
   - 会议旁听智能分析系统 V1.0
3. 程序保持每页不少于 50 行。
4. 文档保持每页不少于 30 行。
5. 程序和文档中的软件名称、版本号、功能描述必须一致。

## 三、文件命名建议

- 申请表：`会议旁听智能分析系统V1.0_申请表.pdf`
- 程序鉴别材料：`会议旁听智能分析系统V1.0_源程序.pdf`
- 文档鉴别材料：`会议旁听智能分析系统V1.0_软件说明书.pdf`
- 营业执照：`营业执照.pdf`
- 身份证：`身份证.pdf`

## 四、易被补正的问题

1. 软件名称前后不一致。
2. 版本号一个写 `V1.0`，另一个写 `1.0`。
3. 文档功能和代码内容对不上。
4. 程序页数不足且又不是全部程序。
5. 最后一页程序不是正常收尾。
6. 申请人名称与营业执照不一致。
7. 软件说明书写得太泛，无法对应系统页面和功能。

## 五、本项目最终提交前建议再核对

1. 是否补入首页、对话页、后台页截图。
2. 是否将著作权人信息替换为真实主体。
3. 是否确认开发完成日期和发表状态。
4. 是否导出生成后的程序鉴别材料。
5. 是否将 Markdown 转为更稳定的 PDF 版本。
