# 会议旁听智能分析系统 V1.0 软件测试说明

## 1. 文档目的

本说明用于概述“会议旁听智能分析系统 V1.0”的基本测试情况，证明该软件已达到可运行、可操作和可交付状态，可作为软著归档或补充性材料使用。

## 2. 测试环境

### 2.1 硬件环境

- 普通办公电脑
- 具备网络访问能力
- 具备音频采集能力

### 2.2 软件环境

- Windows 10/11
- Node.js 18 及以上
- Python 3.10 及以上
- Chrome 或 Edge 浏览器

## 3. 测试对象

测试对象为“会议旁听智能分析系统 V1.0”，主要覆盖以下模块：

1. 首页与导航模块
2. 同事画像对话模块
3. 编号后台模块
4. 编号用户会话存储模块
5. 用户画像分析模块
6. 同事画像管理模块
7. 流式回复模块

## 4. 测试项与结果

### 4.1 首页访问测试

- 测试内容：访问首页并检查主要入口是否可见。
- 预期结果：首页正常展示，存在“同事画像对话”“编号后台”等入口。
- 测试结果：通过。

### 4.2 对话页面访问测试

- 测试内容：进入同事画像对话页面，检查编号分配、对话输入和消息显示区域。
- 预期结果：页面正常展示，能够选择画像并进入对话流程。
- 测试结果：通过。

### 4.3 编号用户会话隔离测试

- 测试内容：使用不同编号用户进入系统，检查历史记录是否相互独立。
- 预期结果：不同编号下的会话记录独立保存，不相互混淆。
- 测试结果：通过。

### 4.4 后台查询测试

- 测试内容：进入后台页面查看编号用户、画像会话和历史消息。
- 预期结果：后台可正常展示编号用户列表、会话列表和消息详情。
- 测试结果：通过。

### 4.5 用户画像展示测试

- 测试内容：在后台页面查看用户画像折叠卡片，执行展开与刷新。
- 预期结果：用户画像可正常显示、折叠、展开和刷新。
- 测试结果：通过。

### 4.6 同事画像基础管理测试

- 测试内容：执行新增画像、修改名称和删除画像操作。
- 预期结果：画像管理操作可正常完成，删除时存在二次确认。
- 测试结果：通过。

## 5. 测试结论

经测试，“会议旁听智能分析系统 V1.0”主要功能可正常运行，页面访问、会话管理、用户画像分析、后台审阅和画像管理等核心能力具备可操作性和稳定性，可满足软著申报中对软件已完成和可运行状态的基本证明需求。
